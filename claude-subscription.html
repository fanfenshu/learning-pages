02学习要点解读 · 我们提炼

  1. IP 是第一位的，要干净、独享。作者说其中“最最重要的就是 IP 地址”，理由是 Claude 有连坐机制，同 IP 有人被封你可能被连累。他的做法是租海外服务器。依据：原话 0:13–0:36
  2. 用检测页当仪表盘，全绿再登录。IP、IPv6、时区、DNS、语言，逐项调到检测页显示正常；顺序不能反，每次重启电脑都先查一遍。依据：原话 2:14–2:37 · 检查清单
  3. IPv6 是最容易漏的一项。IPv4 已经是服务器地址了，IPv6 还暴露着“中国 青岛”，信任评分直接是 0。关掉网卡的 IPv6 后才变好。依据：对比动图 1:04
  4. Claude Code 放进专用虚拟机，一机一号。虚拟机里只装浏览器、VS Code、Claude 桌面端；不切换账号、不接国产模型，想折腾就去宿主机或另开虚拟机。依据：原话 3:59–4:53
  5. 账号要养：先聊再升级，用量别打满。免费号聊几个月再升 Pro，Claude Code 额度每月留 20%–30%，稳定后再升 Max；用大号时永远养着 2 到 3 个小号。依据：养号动图
  6. 有些流传的规矩，作者认为没必要。“只能在美国白天用”“必须用英语对话”，作者说自己和很多人都是中国作息 + 中文对话，目前没出问题。这是他的经验，没有数据。依据：原话 5:24–5:38
